# 代码练习指南

GoCampus 的代码练习位于仓库的 `code/` 目录。题目、测试和参考答案放在一起，适合在阅读文档后立即验证所学内容。

## 推荐流程

1. 进入题目目录，先阅读其中的 `README.md`。
2. 独立完成题目要求，不要提前查看 `answer/answer.go`。
3. 运行测试，根据失败信息修改实现。
4. 测试通过后再与参考答案对照，记录不同的设计选择。

## 运行测试

在仓库根目录执行：

```bash
# 运行全部练习
cd code
go test ./...

# 运行一道题（示例）
cd code/phase1/01_slice/01_deep_copy
go test -v

# 统计整体完成情况
cd code
bash scripts/judge.sh
```

## 本地启动文档站

项目使用 VitePress 构建学习文档。首次使用时安装依赖，然后启动开发服务器：

```bash
npm install
npm run docs:dev
```

根据终端提示打开本地地址。修改 `docs/` 内的 Markdown 后，页面会自动刷新。

发布前可执行完整构建检查：

```bash
npm run docs:build
npm run docs:preview
```
