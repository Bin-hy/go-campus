# Phase 3 代码练习

本目录包含第三阶段（AI 应用开发基础）的所有代码练习和项目。

## 目录结构

```
01_llm_basics/          — LLM API 调用练习（Day 1-2）
02_prompt_engineering/  — Prompt 技巧实践（Day 3-4）
03_embedding/           — Embedding 与向量检索（Day 5-7）
04_rag_project/         — RAG 问答项目（Day 8-14，阶段产出）
```

## 前置准备

1. 准备一个 OpenAI 兼容的 API Key（推荐 DeepSeek 或豆包，国内访问稳定且便宜）
2. 设置环境变量：
   ```bash
   export LLM_API_KEY="your-api-key"
   export LLM_BASE_URL="https://api.deepseek.com/v1"  # 或其他兼容接口
   export LLM_MODEL="deepseek-chat"
   ```
