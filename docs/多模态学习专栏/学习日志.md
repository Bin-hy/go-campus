# 学习日志

> **用途**：每次学习后追加一条记录。这是本专栏的"记忆"——三个月后你会忘记当时卡在哪，但这份日志不会。
> **格式要求**：一条记录只写四件事——**学了什么 / 卡在哪 / 下一步 / 状态变更**。不要写成读书笔记（读书笔记属于深度篇）。
> **为什么值得写**：面试官最爱问「你遇到过什么问题、怎么解决的」。这份日志就是你的素材库，尤其是"踩过的坑"那部分——假装懂的人讲不出来。

## 记录模板（复制这一段使用）

```markdown
### YYYY-MM-DD · <主题>

- **学了什么**：
- **卡在哪**（最重要，写具体到"哪个公式/哪句解释看不懂"）：
- **动手跑了什么**（命令、结果、和预期差在哪）：
- **下一步**：
- **总表状态变更**：把 <知识点编号> 从 ⬜ 改为 ✅ ...

### 深度篇触发

- [ ] 需要新建深度篇：<知识点>，原因：<面试被问住 / 发现专栏表述与论文冲突 / 实验结果不符>
```
