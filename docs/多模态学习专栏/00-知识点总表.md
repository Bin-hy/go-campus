## 一、状态标记与掌握度标准

| 标记 | 含义 | 判定标准（必须能用嘴说出来才算） |
|------|------|--------------------------------|
| ⬜ | 未学 | 名词听过或不认识 |
| 🔄 | 在学 | 看得懂别人的解释，但自己讲不利索 |
| ✅ | 已掌握 | 能说清「解决了什么问题、代价是什么、什么时候不该用」三件事 |
| ⭐ | 能讲透 | 能补充数值量级、能对比替代方案、能说出失败案例或踩过的坑 |

**权重说明**：`P0` = 面试必问且高频，不掌握直接减分；`P1` = 高频追问面，掌握后明显加分；`P2` = 加分项，读懂即可。

**可复现性说明**：`✅` M5 单机可跑 / `⚠️` 只能极小规模或量化推理 / `❌` 只能读懂（不勉强）。

**讲解在哪**：每个知识点的完整讲解就在对应大纲的同号小节里（如本表 `2.4` = 大纲 `2.4` 节），每节统一为「本质 → 为什么 → 机制 → 算例 → 边界 + 面试一句话」。**编号已与大纲逐条对齐**，读大纲时可以直接拿本表当目录勾进度。
