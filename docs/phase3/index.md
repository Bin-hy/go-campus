# 第三阶段：AI 应用开发

本阶段以项目为驱动，通过实战掌握 AI 应用开发全链路。每个项目包含三件套：

- **项目首页**：项目简介、目标、技术栈、进度
- **学习笔记**：相关知识点整理
- **项目设计**：系统架构与实现方案
