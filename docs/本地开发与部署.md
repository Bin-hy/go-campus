# 本地开发与部署

> 本文是仓库的运行手册：怎么把文档站跑起来、怎么判题、怎么起中间件做实验、怎么接入批注与评论，以及怎么部署到 Cloudflare Pages。
> 只想先读起来？回到 [README](https://github.com/Bin-hy/go-campus#快速开始) 的三条命令即可。

## 环境要求

| 依赖 | 版本 | 用途 |
|------|------|------|
| Node.js | 22（Cloudflare Pages 构建版本） | VitePress 文档站 |
| Go | 1.22 / 1.25（各模块独立 `go.mod`） | 练习与实验代码 |
| Docker + Compose | 任意近两年版本 | MySQL / Redis / Kafka / MinIO / Milvus / etcd 实验 |
| 可选 minikube | — | `code/k8s/` 的集群实操 |

## 文档站

```bash
npm install
npm run docs:dev        # http://127.0.0.1:5173
npm run docs:build      # 静态产物到 docs/.vitepress/dist
npm run docs:preview    # 本地预览构建产物
```

构建前的 `predocs:build` 会自动执行 `docs:sync-exercises`：扫描 `code/` 下的练习，重新生成 `docs/习题集和答案/`，**文档与代码永远不会脱节**。

两个辅助脚本：

```bash
npm run docs:check-mermaid          # 检查 mermaid 图尺寸是否超标
npm run docs:check-mermaid:strict   # CI 用严格模式，超标即失败
```

## 划线批注（可选，需登录）

文档站通过可嵌入 SDK 接入独立的 **朱批（zhupi）** 批注服务（多站点、支持 GitHub / 站点级 OIDC）。
未配置 `VITE_ANNOTATION_*` 时不会加载 SDK，不影响阅读与 Artalk 评论。

```bash
# 终端 A：批注服务（位于与本仓库同级的 zhupi/）
cd ../zhupi
make build
export SECRET_KEY=$(openssl rand -hex 32) DB_PATH=./zhupi.db \
       PUBLIC_BASE_URL=http://127.0.0.1:8080 DEV_LOGIN=1
./bin/zhupi admin site create --name gocampus --origin http://127.0.0.1:5173
./bin/zhupi serve

# 终端 B：文档站（<siteKey> 换成上一步输出）
VITE_ANNOTATION_API=http://127.0.0.1:8080 VITE_ANNOTATION_SITE_KEY=<siteKey> \
npm run docs:dev
```

页面体验：文档页顶部导航提供「批注 N」与登录/头像入口；页面之间用 SDK 的 `setPage` 单实例切换，首页/404 自动隐藏；SDK 跟随 VitePress 暗色主题，抽屉从顶栏下方展开。

## Cloudflare Pages 部署

`VITE_*` 只在**构建期**读取，需要在 Pages 项目的 **Settings → Environment variables** 配置（Production 与 Preview 都建议配置）：

| 变量 | 当前生产值 | 说明 |
|------|-----------|------|
| `VITE_ANNOTATION_API` | `https://zhupi.gataccay.com` | 批注服务地址 |
| `VITE_ANNOTATION_SITE_KEY` | `2w1fyqdW1M2Xc4JPJOg-d35XmuqeKYOE` | zhupi 站点 `gocampus` 的公开标识 |
| `VITE_ARTALK_SERVER` | `https://artalk.gataccay.com` | 评论服务地址 |
| `VITE_ARTALK_SITE` | `gocampus训练营` | Artalk 站点名（区分大小写） |

Pages 构建配置：

- Build command：`npm run docs:build`
- Build output directory：`docs/.vitepress/dist`
- Node.js：22

注意事项：

- 文档站入口：<https://gocampus.gataccay.com>（另有 `go-campus.pages.dev` 预览域名）。
- `VITE_ANNOTATION_SITE_KEY` 是公开标识，不是密钥；访问控制由 zhupi 的站点来源白名单负责。
- zhupi 站点 `gocampus` 已允许 `https://gocampus.gataccay.com`、`https://go-campus.pages.dev`、`https://main.go-campus.pages.dev`。新增自定义域名或预览域名时，需要在 zhupi 管理后台（站点 → 编辑 → 允许来源）或 `PATCH /api/v1/admin/sites/{id}` 中同步补 origin。
- 环境变量只在构建时注入，修改后必须重新部署一次才会生效。

## 常见问题

**Q：`npm run docs:dev` 报 mermaid 相关的 CJS/ESM 错误？**
A：`config.mts` 已用 `optimizeDeps.include` 强制预构建 `mermaid > fastdom`。若仍报错，删除 `node_modules/.vite` 后重启。

**Q：构建时报死链？**
A：站点内跨栏目链接用绝对路径（`/架构师修炼/...`），栏目内用相对路径；改文件名后记得全局搜索旧链接。

**Q：练习答案会被提交吗？**
A：不会。提交 `solution.go` 骨架后对该文件设置 `skip-worktree`（或在 `.gitignore` 中忽略），避免个人答案污染仓库。
