# .specs — 栏目设计过程产物

本目录存放各内容栏目的 **spec / plan / task / checklist** 等开发过程文档，按栏目名分子目录。

```
.specs/
├── k8s-code教程/      # 教程章节结构、代码目录、技术决策
├── 主流agent拆解/     # pi / Eino / LangGraph 拆解模块的设计记录
└── 架构师修炼/        # 架构栏目（含 19 pprof 实战）的设计记录
```

## 约定

- **不参与站点导航**：这些文档不在 `docs/` 内，VitePress 不会构建也不会有侧边栏入口，纯内部维护用。
- **一个栏目一个目录**：与 `docs/<栏目>/` 同名，便于对照。
- **记录设计意图**：为什么这样分章、为什么这类内容独立成栏目、验收标准是什么。

## 历史说明

`.specs/主流agent拆解/` 记录的是该模块从 `docs/phase3/` 迁出时的完整过程，其中的路径字符串（如 `phase3/pi-harness`）反映**迁移当时**的状态，不代表当前目录结构。

当前 `docs/` 下的项目实战栏目路径为 `docs/项目实战/`。
